# Mike Bostock

Creator of D3.js and Observable. Published an influential [[bostock-2012-d3-hive-plots|hive plot implementation and writeup]] in March 2012, applying [[hive-plot|hive plots]] to the Flare visualization toolkit's dependency graph.

## Contribution to Hive Plots

- Built a D3.js v2 hive plot implementation with a custom cubic Bézier `link()` shape generator
- Popularized hive plots in the web visualization community
- Articulated the "wasted position channel" critique of [[force-directed-layout|force-directed layouts]]
- Published companion gists: Hive Plot (Links) and Hive Plot (Areas)

## Key Quote

> "Many methods of graph drawing, such as force layouts, do not assign intrinsically-meaningful positions to nodes: the position is only approximate, in the hope that related nodes appear nearby. While intuitive, these methods arguably make poor use of the most effective visual channel (that is, *position*)."
