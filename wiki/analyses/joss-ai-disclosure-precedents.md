# JOSS AI-Disclosure Precedents

Evidence to calibrate the wording of the JOSS paper's **mandatory AI-usage disclosure** section. Gary's recorded posture is **middle**: disclose that Claude is used in implementation and documentation as of 2025, with a human signing off on all code; no deep agent-harness detail by default. Final wording stays **gated on Gary's review** in Workstream C. All examples accessed 2026-06-12.

## The policy

Per joss.readthedocs.io/en/latest/paper.html, the **AI usage disclosure** is a **required section**, placed **after the Research Impact Statement and before Acknowledgements**. Verbatim requirement:

> "Transparent disclosure of any use of generative AI in the software creation, documentation, or paper authoring. If no AI tools were used, state this explicitly. If AI tools were used, describe how they were used and how the quality and correctness of AI-generated content was verified."

Editorial context: Arfon Smith, "Preparing JOSS for a generative AI future," 2026-01-05.

## Accepted-paper examples, by posture

### Minimal ("none")

- **nyaml** — 10.21105/joss.10231
- **Vibrant** — 10.21105/joss.10136
- **TikhonovFenichelReductions.jl** — 10.21105/joss.09924

### Scoped middle (closest to a tighter version of Gary's posture)

- **Chemiscope 1.0** — 10.21105/joss.10380:
  > "Generative AI tools were used occasionally during software development (e.g. to obtain code suggestions). All AI-generated suggestions were reviewed, modified, and verified by the authors before inclusion, and the authors take full responsibility for the final content of the software."
- **CGView.js** — 10.21105/joss.09930:
  > "Generative AI (ChatGPT) was used occasionally for issue triage, small code suggestions, and copy editing of documentation and this manuscript. All AI-assisted code and text were reviewed and verified by the authors. No figures or data were generated by AI."
- **ScrollStats** — 10.21105/joss.09736:
  > "Generative AI was used to create a limited number of docstrings and provide implementation examples... Generative AI was not used in the writing of this manuscript or any other supporting materials."

### Detailed (closest to hiveplotlib's actual workflow)

- **scpviz** — 10.21105/joss.10303:
  > "Generative AI tools were used during the development of this work to assist with code refactoring, documentation drafting, and manuscript text editing. All software design decisions, implementation, validation, and scientific interpretation were performed and reviewed by the authors. No generative AI tools were used to generate or analyze research data, and all results reported are reproducible from the publicly available source code and documentation."
- **PAI** — 10.21105/joss.10245: used for paper writing, documentation, and Java-to-C++ translation with extensive manual checking, all reviewed/validated by authors.

## Pattern

The mandated trio is **(where AI was used → what kind of assistance → human verified and owns it)**. Most disclosures run **1–4 sentences**. Naming the model is encouraged but several name only "generative AI" / "ChatGPT."

## Recommendation for hiveplotlib

hiveplotlib's real workflow (Claude Code across code, tests, docs, and notebooks) fits the **scpviz / PAI detailed end**, not the minimal one. A recommended starting draft:

1. **Names the tool** (Claude / Claude Code).
2. **Enumerates the task types** (implementation, tests, documentation, example notebooks).
3. **Affirms human design ownership and verification** — design decisions are the author's; correctness is verified by the test suite (100% coverage), CI, and human review.

This is a *starting point* for Workstream C drafting. Final wording is **gated on Gary's explicit review** before the paper is called done.
